# 鱼乐圈 AnglerCircle — UI 页面资产

## 视觉规范
- 主色：深海蓝、橙金、白；不使用大面积绿色。
- 气质：专业户外、地图工具、钓鱼社区。
- 地图：高德/百度地图能力按产品方案提供切换。
- 页面单图独立，地图文字、钓点标记和鱼获信息必须清晰。

## 页面模块
1. 启动、登录、首页、地图总览。
2. 钓点地图、钓点列表、钓点详情、新增/编辑/纠错、收藏、打卡。
3. 鱼获发布、鱼获详情、鱼种记录、渔获相册。
4. 社区动态、评论、点赞、收藏、话题。
5. 好友、好友申请、分组、授权轨迹查看。
6. 个人主页、积分、排行榜、成就。
7. 地图设置、定位授权、隐私控制。
8. 运营后台、钓点审核、鱼获审核、用户管理、红安审核状态。

## 状态
所有页面待逐张生成。位置和轨迹相关界面必须突出授权、可见范围和撤回入口。
