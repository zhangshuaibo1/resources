# 知更鸟 ROBIN — UI 页面资产

## 视觉规范
- 主色：知更鸟橙、奶油白、深墨色；避免绿色大面积铺底。
- 气质：企业情报、法律知识、标准合规、专业 SaaS。
- 核心：原文来源可追溯、法规效力状态清晰、企业信息安全。

## 页面模块
1. 官网、登录、企业工作台首页、全局搜索。
2. 法律法规中心、法规详情、条文详情、效力状态、版本对比。
3. 标准合规中心、标准详情、替代关系、产品合规映射。
4. 产业政策中心、政策详情、申报指南、政策匹配。
5. 技术专利中心、专利详情、技术趋势。
6. 招投标机会中心、项目详情、截止提醒。
7. 企业画像、产品档案、企业 AI 助手。
8. 合同分析、企业知识库、文档问答、引用来源。
9. 订阅管理、通知中心、团队协作、企业权限。
10. 数据源管理、采集监控、AI 任务、用量统计、运营后台。

## 状态
所有页面待逐张生成。法律和标准页面必须呈现来源、版本、日期和效力状态，不得把 AI 生成内容伪装成官方原文。
