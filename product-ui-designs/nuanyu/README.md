# 暖遇 NUANYU — UI 页面资产

## 视觉规范
- 主色：暖橙、奶油白、浅棕；避免绿色主视觉。
- 气质：温暖、现代、轻松、可信。
- 产品：好友/陌生人兴趣组局、公开多人活动、生活图文视频笔记。
- 页面按手机小程序优先，运营后台另做 Desktop 单页。

## 页面模块
1. 品牌启动页、登录、手机号认证、首页、发现。
2. 找搭子、七大活动分类、活动列表、活动详情。
3. 发起活动、报名确认、组织者确认、成局与取消。
4. 微信好友分享、内部好友、通知中心。
5. 生活笔记流、写文字、图文编辑、视频上传、笔记详情。
6. 我的笔记、收藏、个人主页、隐私与可见范围。
7. 安全中心、举报、拉黑、投诉、账号注销。
8. 商家/场馆主页、活动管理。
9. 运营后台、内容审核、红安审核结果与人工复核。

## 状态
所有页面待逐张生成。公开社交、评论、聊天和线下活动页面须遵循已确认的类目及合规边界。
